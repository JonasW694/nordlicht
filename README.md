# Nordlicht-Radar

Web-App für iPhone und Mac: Bewölkung, Polarlicht-Chance, Wolkenlücken-Suche mit Navigation und Drohnenzonen (Norwegen, Schweden, Finnland, Deutschland).

App: https://jonasw694.github.io/nordlicht/

iPhone: Adresse in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Daten: NOAA SWPC, Open-Meteo, Kartverket, OpenStreetMap, Miljødirektoratet, EEA, DFS dipul, OurAirports. Alle Angaben ohne Gewähr, vor jedem Drohnenflug die offiziellen Karten prüfen.
